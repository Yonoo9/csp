

git diff показывает различия между версиями файлов.

git show показывает информацию и изменения конкретного коммита.

git log показывает историю коммитов.

git log -S"def" -- lab03/calc.py находит коммиты, в которых изменилось количество вхождений "def" в файле.

git blame lab03/calc.py показывает, кто и в каком коммите последним изменил каждую строку файла.
