

git diff показывает различия между версиями файлов.

git show показывает информацию и изменения конкретного коммита.

git log показывает историю коммитов.

git log -S"def" -- lab03/calc.py находит коммиты, в которых изменилось количество вхождений "def" в файле.

git blame lab03/calc.py показывает, кто и в каком коммите последним изменил каждую строку файла.



git restore lab03/calc.py восстанавливает файл из индекса, обычно это версия после последнего git add. git restore --source=HEAD\~2 lab03/calc.py восстанавливает файл из указанного коммита, в данном случае из коммита двумя шагами ранее. Незакоммиченные изменения могут быть потеряны.



git revert HEAD создаёт новый коммит, который отменяет изменения предыдущего коммита, при этом исходный коммит остаётся в истории.

git reset --hard перемещает текущую ветку на указанный коммит и сбрасывает индекс и рабочие файлы, из-за чего незакоммиченные изменения теряются. В опубликованной истории безопаснее использовать revert, потому что он не переписывает историю и не мешает другим участникам работать с уже опубликованными коммитами.
